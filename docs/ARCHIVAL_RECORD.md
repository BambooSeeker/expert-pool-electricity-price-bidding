# Archival Record

Version 1.0.1 is archived on Zenodo under DOI `10.5281/zenodo.22291573`.

The Zenodo record is the immutable release cited by the accompanying manuscript. The GitHub repository hosts the maintained source and may receive later versions. Each archived version retains its own files and checksum manifest.

The archive contains the seven-day demonstration, frozen local-expert parameters, derived whole-day residual medoids, unit configuration, expected numerical outputs, and the code required to run the public inference and bidding checks. The complete source market table and unrestricted training matrices remain outside the public release under the authors' data-use arrangements.
